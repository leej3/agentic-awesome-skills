# Interface review workflow

Start with the user’s task and the information they need for each decision.
Map the primary selection, scoped results, detail view, and return path.
Use the same labels and scope throughout that path.

- Show what is selected and what each count measures.
- Separate primary navigation from contextual evidence.
- Preserve selection and position when opening and closing detail.
- Explain unavailable evidence and empty results near the affected control.
- Use semantic controls, visible focus, descriptive labels, and keyboard access.
- Verify the complete flow with representative real data and a browser test.

Record observed behavior and remaining limitations. Do not infer usability from visual polish alone.
